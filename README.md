# MedShift

## Sistema de apoio à construção e validação de escalas médicas

O MedShift é um sistema desenvolvido para auxiliar os colaboradores do Hospital Aurora na criação e validação de escalas médicas.

Antes, as escalas eram elaboradas manualmente, tornando o processo mais suscetível a conflitos de horário, ausência de especialidades, 
distribuição inadequada de profissionais entre turnos e outros erros operacionais. O MedShift digitaliza esse processo, oferecendo uma 
forma mais rápida, organizada e confiável de montar as escalas.

### Tecnologias utilizadas
- Visualg (algoritmo)
- Git/GitHub (versionamento)
